title: 数据安全
edition: dms

:::caution DMS 专有功能
数据安全模块仅在 DMS 版本中可用。
:::

数据安全模块帮助企业对数据库账号、角色权限和敏感数据实施全方位管控，确保数据访问安全可控。

## 本章内容

| 功能 | 说明 | 适用角色 |
|------|------|---------|
| [数据脱敏](../project/data_masking.md) | 自动识别敏感字段并配置脱敏规则，保障查询和导出场景中的数据安全 | 安全管理员 / DBA |
| [角色管理](../project/data_access_control/permission_template.md) | 查看和管理数据源上的数据库角色 | DBA |
| [账号管理](../project/data_access_control/authorization_list.md) | 发现、创建和管理数据库账号 | DBA |
| [临期密码](../project/data_access_control/expiring_password.md) | 监控到期密码并及时处理 | DBA |
