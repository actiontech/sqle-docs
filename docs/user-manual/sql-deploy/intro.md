title: SQL 上线
---

SQL 上线涵盖 SQL 变更工单从创建、审核到执行上线的完整流程，以及回滚和版本管理能力，确保 SQL 变更安全、有序地部署到目标环境。

## 本章内容

| 功能 | 说明 | 适用角色 |
|------|------|---------|
| [SQL 工单](../project/workflow/intro.md) | SQL 变更上线的标准化流程总览 | 开发 / DBA |
| [创建工单](../project/workflow/create-workflow.md) | 提交 SQL 变更工单并获取审核结果 | 开发 |
| [审核工单](../project/workflow/audit-workflow.md) | 审核工单中的 SQL 质量，通过或驳回 | DBA |
| [上线工单](../project/workflow/exec-workflow.md) | 选择上线方式执行 SQL 变更（立即 / 定时 / 人工） | DBA |
| [回滚](../project/workflow/rollback.md) | 利用备份数据进行回滚操作 | DBA |
| [版本管理](../project/workflow/version-management.md) | 组织和跟踪数据库变更在多环境中的发布流程 | 开发 / DBA |
