---
title: 账号管理
---

:::caution DMS 专有功能
账号管理功能仅在 DMS 版本中可用。
:::

账号管理提供数据源上数据库账号的全生命周期管理，包括账号发现、创建、密码托管和授权操作。

## 功能入口

进入项目后，点击左侧导航栏 **数据安全** → **账号管理**。

## 概览面板

页面顶部展示账号统计：

| 指标 | 说明 |
|------|------|
| 全部账号 | 所有已发现和已创建的账号总数 |
| 可用账号 | 状态正常、可正常使用的账号数量 |
| 禁用账号 | 已被禁用的账号数量 |
| 临期账号 | 密码即将到期或已到期的账号数量 |

## 账号列表

| 列名 | 说明 |
|------|------|
| 账号 | 数据库账号名称 |
| 数据源 | 账号所属的数据源 |
| 密码有效期 | 密码的到期时间 |
| 密码到期策略 | 密码到期后的处理方式（保持可用 / 自动锁定） |
| 账号状态 | 当前状态：可用 / 已锁定 |
| 托管密码 | 是否已将密码托管至平台（已托管 / 未托管） |
| 账号授权 | 该账号被授权的平台用户 |
| 说明 | 账号的备注信息 |

## 主要操作

### 账号发现

点击 **账号发现** 按钮，平台将自动扫描数据源上已存在的数据库账号并导入到账号列表中。

### 创建账号

点击 **创建账号** 按钮，在数据源上创建新的数据库账号。

### 查看账号详情

点击账号行的 **查看** 按钮，查看账号的详细信息，包括权限、连接信息等。

### 授权

对已托管密码的账号，点击 **授权** 按钮，将数据库账号授权给平台用户使用。被授权的用户可通过 SQL 工作台等功能使用该账号连接数据源。

### 批量修改密码

勾选多个账号后，点击 **批量修改密码** 按钮，统一修改所选账号的密码。

## 密码托管

平台支持将数据库账号的密码进行托管管理：

- **已托管**：密码由平台统一管理，支持密码到期策略、自动锁定等功能
- **未托管**：平台仅记录账号信息，不管理其密码

:::tip
建议对生产环境的数据库账号启用密码托管，以便统一管控密码生命周期。
:::
