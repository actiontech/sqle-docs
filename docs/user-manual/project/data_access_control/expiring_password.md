---
title: 临期密码
---

:::caution DMS 专有功能
临期密码功能仅在 DMS 版本中可用。
:::

临期密码页面集中展示密码即将到期或已到期的数据库账号，帮助 DBA 及时处理，避免因密码过期导致业务中断。

## 功能入口

进入项目后，点击左侧导航栏 **数据安全** → **临期密码**。

## 列表说明

| 列名 | 说明 |
|------|------|
| 账号 | 数据库账号名称 |
| 数据源 | 账号所属的数据源 |
| 密码有效期 | 密码的到期时间 |
| 密码有效时间 | 距密码到期的剩余天数（0 表示已过期） |
| 账号状态 | 当前状态：可用 / 已锁定 |

## 操作

| 操作 | 说明 |
|------|------|
| **修改密码** | 为账号设置新密码，密码有效期将重新计算 |
| **续用当前密码** | 延长当前密码的有效期，无需修改密码 |

:::tip
- 密码到期策略为「自动锁定」的账号，过期后将自动变为「已锁定」状态
- 建议定期巡检临期密码列表，提前处理即将到期的账号
:::
