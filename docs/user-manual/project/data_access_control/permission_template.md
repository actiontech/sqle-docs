---
title: 角色管理
---

:::caution DMS 专有功能
角色管理功能仅在 DMS 版本中可用。
:::

角色管理用于查看和管理数据源上的数据库角色，包括角色拥有的权限和角色之间的继承关系。

## 功能入口

进入项目后，点击左侧导航栏 **数据安全** → **角色管理**。

## 界面说明

页面顶部提供数据源选择器，切换不同数据源查看其角色信息。

| 列名 | 说明 |
|------|------|
| 角色名 | 数据库角色的名称 |
| 已授予的角色 | 该角色继承的其他角色 |
| 已授予权限 | 该角色拥有的数据库操作权限 |
| 操作 | 可对角色执行的管理操作 |

## 使用场景

- **权限审计**：定期检查数据源上的角色权限分配是否合理
- **安全巡检**：确认是否存在权限过大的角色
- **合规检查**：验证角色权限是否符合安全策略
