---
title: 账号安全
---

:::caution DMS 专有功能
账号安全功能仅在 DMS 版本中可用。
:::

账号安全为 DBA 提供数据源级别的账号全生命周期管理能力，包括账号发现、密码托管、角色权限管理与密码到期管控，保障数据源账号安全可控。

## 本章内容

| 功能 | 说明 |
|------|------|
| [角色管理](permission_template.md) | 查看和管理数据源上的数据库角色及其权限 |
| [账号管理](authorization_list.md) | 发现、创建和管理数据源上的数据库账号 |
| [临期密码](expiring_password.md) | 监控即将到期的账号密码，及时修改或续期 |
