---
title: SQL 快捷审核
---

SQL 快捷审核提供独立于工单流程的 SQL 审核能力，适用于开发人员自检、DBA 批量审核等快速验证场景。

## 快捷审核 vs 工单审核

| 对比项 | SQL 快捷审核 | SQL 工单 |
|--------|-------------|---------|
| 目的 | 快速获取审核结果，自检优化 | 标准化上线流程，审核 + 执行 |
| 审核流程 | 即时审核，无需流转 | 按审批流程模板逐级审核 |
| 执行能力 | 不执行 SQL | 审核通过后可执行上线 |

## 前置条件

- 已进入项目页面
- 当前用户为项目成员

## 操作步骤

### 步骤一：新建审核

点击左侧导航栏 **SQL 审核**，进入审核列表页面，点击 **新建** 按钮。

### 步骤二：配置审核参数

#### 审核标签

标签用于分类管理审核记录。系统预置 **全量** 和 **增量** 标签，也可自定义标签。

#### 审核模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 离线审核 | 无需连接数据库，基于 SQL 语法审核。需手动选择数据源类型和审核规则模板 | 快速语法检查、规范性审核 |
| 在线审核 | 连接实际数据库审核，自动使用数据源绑定的规则模板 | 需要执行计划分析的深度审核 |

#### 上传 SQL

| 方式 | 说明 |
|------|------|
| 在线输入 | 直接在编辑器中输入 SQL，支持语法高亮 |
| 上传 XML 文件 | 支持 MyBatis 等框架的 XML 映射文件 |
| 上传 SQL 文件 | 上传 `.sql` 格式文件 |
| 上传 ZIP 文件 | 批量上传，文件大小限制 10MB |
| 配置 Git 仓库 | 支持公开和私有仓库，需配置访问凭证和分支 |

### 步骤三：执行审核

点击 **立即审核** 按钮，获取审核结果。

![SQL 快捷审核](img/quick-audit.png)

### 步骤四：查看结果

审核完成后，可查看每条 SQL 的审核结果和优化建议。审核记录会保存在审核列表中，可随时回顾。

## 后续操作

- 根据审核建议优化 SQL
- 对需要上线的 SQL，创建 [SQL 工单](workflow/create-workflow.md) 进入正式变更流程
- 添加标签的审核记录可在 [SQL 管控](audit_task/sqlmanage.md) 列表中统一查看
