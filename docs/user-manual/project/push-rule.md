---
title: 推送规则配置
---

推送规则可为项目配置工单状态变更通知和高优先级 SQL 通知，确保关键信息及时触达相关成员。

## 前置条件

- 在全局设置中已开启消息推送能力（飞书、钉钉、企业微信等）
- 已在 SQL 管控配置中设定高优先级 SQL 标准（若需推送 SQL 管控通知）
- 当前用户为项目管理员

## 配置步骤

### 1. 进入推送规则设置

点击左侧导航栏 **推送规则**。

### 2. 开启推送功能

| 推送类型 | 说明 |
|----------|------|
| 工单推送 | 工单状态变更时通知相关成员 |
| SQL 管控问题推送 | 定期推送高优先级 SQL 问题 |

每种推送类型可配置：

| 配置项 | 说明 |
|--------|------|
| 推送频率 | 使用 crontab 格式自定义推送频率 |
| 消息接收人 | 选择按权限匹配成员，或直接指定成员 |

### 3. 保存并测试

完成配置后保存。可通过模拟工单状态变更或触发高优先级 SQL 来验证推送效果。
