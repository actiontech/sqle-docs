---
title: SQL 工单
---

SQL 工单是 SQLE 平台的核心功能，提供从 SQL 提交、审核到上线执行的标准化流程，解决 SQL 上线过程中流程不规范、节点不透明的问题。

## 工单流程

![工单流程](img/process.png)

| 状态 | 说明 |
|------|------|
| 待审核 | 工单创建后自动进入，由审批流程模板指定的审核人执行审核 |
| 待上线 | 所有审核节点通过后，由上线人选择上线方式 |
| 正在上线 | SQL 正在执行中 |
| 上线成功 | SQL 执行完成，工单流转结束 |
| 上线失败 | SQL 执行失败，工单流转结束 |
| 已驳回 | 审核人或上线人驳回工单，创建人可修改后重新提交 |
| 已关闭 | 创建人或管理员手动关闭工单 |

## 操作指南

| 操作 | 说明 | 角色 |
|------|------|------|
| [创建工单](create-workflow.md) | 提交 SQL 变更并获取审核结果 | 开发 |
| [审核工单](audit-workflow.md) | 查看工单详情，通过或驳回 | DBA / 审核人 |
| [上线工单](exec-workflow.md) | 选择上线方式执行 SQL | DBA / 上线人 |
| [回滚](rollback.md) | 利用备份进行回滚操作 | DBA |
| [版本管理](version-management.md) | 管理 SQL 变更版本 | 开发 / DBA |
