---
title: 回滚工单
---

回滚功能用于在 SQL 执行导致意外数据修改时，将数据恢复到正确状态。系统通过智能备份推荐、多种备份策略和一键回滚能力，确保数据变更的可靠性和可恢复性。

## 前置条件

回滚功能需要预先开启备份配置，支持两个层级：

| 层级 | 适用范围 | 说明 |
|------|---------|------|
| 数据源级别（推荐） | 该数据源上所有工单 | 在数据源配置中开启 |
| 工单级别 | 仅当前工单 | 创建工单时配置，优先级高于数据源级别 |

## 备份策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 反向 SQL 备份 | 自动生成反向 SQL 语句 | 简单数据修改 |
| 行级备份 | 保存完整行数据历史 | 复杂数据修改 |
| 手工备份 | 用户自定义备份时机和内容 | 特殊业务场景 |
| 无备份 | 不进行数据备份 | 只读或测试场景 |

系统会根据 SQL 语句类型、影响数据量和操作复杂度自动推荐最优备份策略。

## 回滚操作

1. **发起回滚**：在工单详情页点击 **回滚** 按钮
2. **选择范围**：支持表级、行级、字段级回滚
3. **确认执行**：查看回滚预览后创建回滚工单，按正常流程执行

:::tip
- 重要变更建议先在测试环境验证备份和回滚
- 执行回滚前确认回滚范围的准确性
- 定期检查备份状态，确保备份链路正常
:::
