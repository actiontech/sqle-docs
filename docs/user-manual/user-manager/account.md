---
title: 个人中心
---

个人中心允许用户管理自己的账户信息和生成访问令牌。

## 功能入口

点击右上角头像图标，选择 **个人中心**。

## 可管理项

| 功能 | 说明 |
|------|------|
| 修改邮箱 | 更新账户绑定的邮箱地址，用于接收工单通知 |
| 修改企业微信 ID | 更新企业微信关联的用户 ID |
| 修改手机 | 更新账户绑定的手机号码 |
| 生成个人访问 Token | 生成用于 API 访问的个人令牌，可设置失效时间 |

:::tip
个人访问 Token 生成后请妥善保存，平台不会再次明文展示。Token 可用于通过 OpenAPI 访问平台资源。
:::
