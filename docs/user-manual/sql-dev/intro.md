title: SQL 开发
---

SQL 开发覆盖日常 SQL 编写、审核和查询场景，帮助开发人员在提交变更前完成自检和验证。

:::tip
需要提交 SQL 变更？请前往 [SQL 上线](../sql-deploy/intro.md) 模块创建工单。
:::

## 本章内容

| 功能 | 说明 | 适用角色 |
|------|------|---------|
| [快捷审核](../project/quick_audit.md) | 无需创建工单的快速 SQL 审核 | 开发 / DBA |
| [数据导出](../project/dataexport.md) | 通过审批流程安全导出数据 | 开发 / 数据分析师 |
| [SQL 工作台](../sql-workbench/introduction.md) | 在线 SQL 查询与执行，支持审核拦截 | 开发 / DBA |
| [结构对比](../project/Structure-Comparison.md) | 对比不同环境的库表结构差异 | 开发 / DBA |
| [IDE 审核](../project/IDEaudit.md) | 在 IDE 中审核 SQL 并同步结果到平台 | 开发 |
| [CI/CD 集成](../project/CICDintegration.md) | 将 SQL 审核嵌入 CI/CD 流水线 | 开发 / DevOps |
